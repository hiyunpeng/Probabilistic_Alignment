\subsection{Normalised fitness curves with anchors for behavioural attribution}
To mitigate floor/ceiling effects of success-only evaluation, we normalise best objective values within each instance and target tier to obtain a progress score in $[0,1]$ (higher is better). We then form concatenated budget-response vectors across tiers and budgets, standardise features across algorithms, and compare each method to two reference families using anchor curves. In this run, the PSO reference is \texttt{PSO_GBEST} and the ES reference is \texttt{ES_1P1}. We gate ``no-signal'' methods using a headroom threshold on the normalised fitness curves and bootstrap over instances to obtain uncertainty bands.
