# README

## Project archive overview

This archive contains the code and lightweight analysis artifacts used to generate the calibration, verification, figures, and tables for the dissertation experiments.

---

## Where the data came from

The data used in this project were generated by the experiment scripts in this repository rather than downloaded as a large external dataset.

At a high level, the workflow is:

- run anchor calibration experiments,
- combine anchor calibration outputs with the main experiment outputs,
- apply calibrated epsilon thresholds to similarity-pair results,
- run three-direction verification, and
- generate the final dissertation figures and tables.

The main derived data files used downstream are CSV and JSON files created by the scripts listed below, especially:

- `instance_algo_budget_summary.csv`
- `runs_detail.csv`
- `track1_similarity_pairs.csv`
- `epsilon_calibration.json`

These files are generated by the code and then reused by later stages of the pipeline.

## Processing pipeline

### Step 1: Anchor calibration runs

Run:

```bash
python dorigo_run_with_extra_anchors_ladder.py \
  --out_dir ./out_anchor_calibration \
  --algos PSO_GBEST,PSO_RING,ES_1P1,ES_MULAMBDA \
  --budgets 200,300,500,800,1000,1500,2000,3500,5000,8000,12000,15000,20000 \
  --dim 5 \
  --instances_per_problem 20 \
  --dev_frac 0.4 \
  --R 30 \
  --seed 1
```

What this produces:

- anchor calibration experiment outputs in `./out_anchor_calibration`
- raw or semi-processed results used to calibrate epsilon thresholds later in the pipeline

---

### Step 2: Combine anchor calibration with main experiment outputs

Run:

```bash
python dorigo_combine_and_calibrate.py \
  --anchor_dir ./out_anchor_calibration \
  --main_dir ./out_final_dim5 \
  --out_dir ./out_final_dim5_combined \
  --B 2000 \
  --seed 0
```

What this produces:

- combined summary outputs in `./out_final_dim5_combined`
- calibrated epsilon file, typically including:
  - `epsilon_calibration.json`
- merged analysis files, typically including:
  - `instance_algo_budget_summary.csv`
  - `runs_detail.csv`

---

### Step 3: Apply epsilon calibration to similarity pairs

Run:

```bash
python dorigo_apply_epsilons.py \
  --pairs ./out_dorigo_new/verify_tracks/track1_similarity_pairs.csv \
  --eps ./out_final_dim5_combined/epsilon_calibration.json \
  --out_dir ./epsilon_applied
```

What this produces:

- epsilon-adjusted outputs in `./epsilon_applied`
- a processed epsilon calibration JSON used in later analysis

---

### Step 4: Three-direction verification

Run:

```bash
python dorigo_three_directions_verify.py curvesim \
  --csv ./out_final_dim5_combined/instance_algo_budget_summary.csv \
  --out_dir ./out_final_dim5_combined/verify_tracks \
  --view success \
  --B 2000 \
  --eps_frac 0.25 \
  --pso_anchor PSO_GBEST \
  --es_anchor ES_1P1
```

What this produces:

- verification outputs in `./out_final_dim5_combined/verify_tracks`
- similarity-pair and related verification files used by the final reporting stage

---

### Step 5: Generate dissertation figures and tables

Run:

```bash
python dorigo_make_all_figures_tables_v2.py \
  --summary ./out_final_dim5_combined/instance_algo_budget_summary.csv \
  --runs ./out_final_dim5_combined/runs_detail.csv \
  --pairs ./out_final_dim5_combined/verify_tracks/track1_similarity_pairs.csv \
  --eps ./epsilon_applied/epsilon_calibration.json \
  --out_dir ./dissertation_artifacts
```

What this produces:

- final figures and tables in `./dissertation_artifacts`
- the outputs used directly in the dissertation write-up

---

## Recommended execution order

To regenerate the full analysis from code, run the scripts in the following order:

1. `dorigo_run_with_extra_anchors_ladder.py`
2. `dorigo_combine_and_calibrate.py`
3. `dorigo_apply_epsilons.py`
4. `dorigo_three_directions_verify.py`
5. `dorigo_make_all_figures_tables_v2.py`

This order matters because later stages depend on CSV/JSON outputs created earlier.

---

## Reproducibility notes

- The commands above use fixed seeds where provided:
  - `--seed 1` for anchor calibration
  - `--seed 0` for combine/calibration
- The experiments shown here use dimension `5` and the listed budget ladder.
- The pipeline assumes that `./out_final_dim5` already exists before running `dorigo_combine_and_calibrate.py`.
- All paths above are written using forward slashes so they work cleanly on macOS/Linux and usually also on Windows Python shells.
